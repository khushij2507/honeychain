# 5-Minute Demo Script

1. **Problem (30 sec):** Honey supply chains can lose provenance information between harvest, packing and retail. Consumers need an easy way to inspect recorded origin and handling.
2. **Dashboard (45 sec):** Show three synthetic batches, their floral sources, status, quantity and the ledger integrity indicator.
3. **Register a batch (45 sec):** Create a new batch with a unique code. Point out that the first event is added automatically.
4. **Track custody (60 sec):** Open the batch and record a quality check or packing event. Explain that the actor, location, timestamp and event hash are stored.
5. **Consumer view (45 sec):** Open the public verification view. In a real deployment, a QR label would link directly to this URL.
6. **Smart beekeeping (45 sec):** Show telemetry JSON and the environmental indicator. State clearly that this is a transparent rule-based prototype, not a trained disease-detection model.
7. **Integrity check (30 sec):** Open `/admin/verify-chain` and show the validity response. Explain that the hash chain detects tampering but is not equivalent to a distributed blockchain.
8. **Close (20 sec):** Explain next steps: QR printing, login/roles, authenticated IoT devices, externally anchored ledger and a field-validated prediction model.
